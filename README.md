# LifeBatt

Многостраничный русскоязычный прототип сайта производителя аккумуляторов LifeBatt, созданный в Craft Anything. Содержание — LifeBatt; визуальный референс — upgroup.ru.

34 страницы, каталог направлений с поиском и фильтрами, услуги, отрасли применения, FAQ, контакты и локальные формы. Изображения и шрифты хранятся в репозитории.

## Публикация

Адрес демонстрационной версии: https://gwww005-beep.github.io/kiril/

```sh
npm run build:pages
```

Команда собирает и проверяет сайт, затем подготавливает `_site/` для ветки `gh-pages`. На GitHub Pages публикуется корень этой ветки. Демонстрационная версия сохраняет `noindex`; действующий домен LifeBatt и формы отправки не изменяются.

## Локальный запуск

Требуется Node.js 22.18 или новее. Сторонние npm-зависимости для сборки не требуются.

Из корня репозитория:

```sh
npm run build
npm test
npm run preview
```

Предпросмотр: `http://127.0.0.1:4173/`. Обычная сборка создаёт `dist/`, автономный `preview/` и архив `delivery/lifebatt-source.zip`.

```sh
npm run build:production
```

Эта команда готовит локальную сборку для размещения. Она ничего не публикует и не меняет действующий домен.

## Структура

- `src/` — шаблоны, стили, клиентский JavaScript и данные.
- `public/` — локальные изображения, шрифты и значок сайта.
- `scripts/` — сборка, проверки и упаковка.
- `source-content/` — исходные материалы LifeBatt.
- `docs/` — маршруты, дизайн, интеграции и отчёт QA.
- `checks/` — выбранные отчёты с оговоркой об актуальности выше.

Формы не отправляют заявки и не подключены к оплате. По умолчанию прототип закрыт от индексации. Действующий сайт lifebatt.ru и его домен не изменялись. Условия использования сторонних ресурсов указаны в `docs/CREDITS.md` и файлах лицензий шрифтов.
