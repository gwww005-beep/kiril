Запуск после распаковки

Нужен Node.js 22.18 или новее. Откройте терминал в распакованной папке проекта и выполните:

npm install
npm run build
npm run preview

Адрес предпросмотра: http://127.0.0.1:4173/. Остановить сервер — Ctrl+C.

Без команд: откройте preview/index.html из архива в обычном браузере. В архив включены README с инструкциями, исходники, изображения, локальные шрифты и документы миграции.
