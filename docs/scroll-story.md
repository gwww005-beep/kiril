# Анимация сборки LifeBatt — 8 ноября 2026

На главной странице добавлен согласованный пользователем сценарий: ячейки → соединения → BMS → корпус → питание и LifeBatt. SVG и сценарий созданы для LifeBatt; графика и бренд ЮНИПРО не использованы.

Анимация связана с положением прокрутки и обратима. На компьютере слева зарезервировано место; на телефоне используется компактная полоса под шапкой. При открытом мобильном меню она скрыта. При prefers-reduced-motion показана собранная батарея без движения. Декоративная графика исключена из клавиатурной и экранной навигации.

Проверено: 170 статических проверок, 36 DOM-проверок сайта, 17 проверок сценария. В браузере: движение вперёд/назад, восстановление позиции после перезагрузки, ширины 1440/768/390, меню; переполнения страницы не обнаружено. Все 34 страницы и 3773 внутренних пути проходят сборку для GitHub Pages.

Проверки выполнены на экспорте исходного проекта. Изменения исходников и собранного предпросмотра синхронизированы в существующий Craft-проект; его прежний статус needs_you относится к старой проверке приватного браузера. Новый сборщик Craft и второй локальный сервер не запускались.

Формы сохраняют локальную проверку без сетевой отправки. Действующий домен lifebatt.ru не изменён. Интерактивная энергосхема из Instagram по-прежнему не входит в задачу.
