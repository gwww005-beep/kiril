# Источники

Содержание, отзывы и иллюстрации: материалы LifeBatt, предоставленные заказчиком в lifebatt-craft. Соответствия изображений исходным страницам сохранены в source-content/assets-manifest.json. Изображения не являются паспортными карточками товаров.

Визуальное направление: предоставленные снимки UP Group, capture.json, DESIGN.md и согласованный макет LifeBatt. Исходный HTML/CSS/JavaScript UP Group не читался и не импортировался.

Golos Text: Google Fonts, https://github.com/google/fonts/tree/main/ofl/golostext. Font blob 05ee5ecc570b97818e24e58693662cd8294fdfc9. Лицензия — public/fonts/OFL-golos-text.txt.

JetBrains Mono: Google Fonts, https://github.com/google/fonts/tree/main/ofl/jetbrainsmono. Лицензия — public/fonts/OFL-jetbrains-mono.txt.

LinkeDOM: официальный https://github.com/WebReflection/linkedom, worker.js используется только в локальных тестах. Лицензия — scripts/vendor/LICENSE-linkedom.

Иконки интерфейса — собственные простые SVG. Используемые фотографии оптимизированы в WebP без изменения их содержания.
