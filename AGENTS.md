# LifeBatt: контекст проекта

Этот репозиторий содержит экспорт существующего проекта Craft Anything для LifeBatt. Содержание и услуги — lifebatt.ru; у upgroup.ru используется только оформление. Не переносить бренд ЮНИПРО, чужие тексты, архитектурные проекты и маршруты ради процента сходства.

Сохранять все 34 страницы, фотографии, компоновку, меню, поиск, фильтры и локальные формы без сетевой отправки. Утверждённая палитра: #0A1430 / #0297DE / #FC734D. Основные кнопки оранжевые с тёмным текстом, основной текст светлый.

Палитра применена. Пользователь согласовал и добавлена скролл-анимация сборки аккумулятора на всех 34 страницах: ячейки → соединения → BMS → корпус → питание LifeBatt. Сценарий обратим, поддерживает мобильный экран и prefers-reduced-motion. Экспорт для GitHub Pages собран: 170 статических + 36 DOM + 223 проверки анимации прошли; все 34 страницы и 3807 внутренних пути подготовлены для /kiril/. Актуальное состояние — README.md и checks/github-pages-report.json; прежние заметки о блокировке относятся только к запуску внутри Craft.

Не реализовывать пока не согласованную интерактивную энергосхему из Instagram. Не менять действующий сайт, домен или оплату и не отправлять реальные заявки без отдельного задания.

Уточнение пользователя: графика накладывается на свободное поле на всех страницах, без дополнительной колонки и смещения контента. На главной — после героя; на внутренних — после первых 120 px прокрутки. Начальный и последующие блоки выровнены по общей сетке; сверху на телефоне нет дополнительной полосы и отступа. Проверена каждая страница при 1440/390; основные шаблоны также при 1920/768. Подробности — docs/scroll-story.md.
