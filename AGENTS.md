# LifeBatt: контекст проекта

Этот репозиторий содержит экспорт существующего проекта Craft Anything для LifeBatt. Содержание и услуги — lifebatt.ru; у upgroup.ru используется только оформление. Не переносить бренд ЮНИПРО, чужие тексты, архитектурные проекты и маршруты ради процента сходства.

Сохранять все 34 страницы, фотографии, компоновку, меню, поиск, фильтры и локальные формы без сетевой отправки. Утверждённая палитра: #0A1430 / #0297DE / #FC734D. Основные кнопки оранжевые с тёмным текстом, основной текст светлый.

Палитра применена. Пользователь согласовал и добавлена скролл-анимация сборки аккумулятора на главной: ячейки → соединения → BMS → корпус → питание LifeBatt. Сценарий обратим, поддерживает мобильный экран и prefers-reduced-motion. Экспорт для GitHub Pages собран: 170 статических + 36 DOM + 24 проверки анимации прошли; все 34 страницы и 3773 внутренних пути подготовлены для /kiril/. Актуальное состояние — README.md и checks/github-pages-report.json; прежние заметки о блокировке относятся только к запуску внутри Craft.

Не реализовывать пока не согласованную интерактивную энергосхему из Instagram. Не менять действующий сайт, домен или оплату и не отправлять реальные заявки без отдельного задания.

Уточнение: первый экран занимает всю ширину и остаётся без анимации. Рисунок появляется после того, как герой уходит за шапку; отсчёт сборки начинается с этой точки. Возврат к первому экрану скрывает рисунок. На телефоне также убран начальный отступ под полосу. Проверено на ширинах 1920/1440/768/390.
